## 4. 运行方式

### 基础（契约/清洗，无需重模型）
```bash
cd doc-processor
uv sync                          # 只装基础依赖（ml/pdf 不落盘）
uv run pytest -q                 # 5/5
uv run uvicorn app.main:app --port 8000
```

### 全能力（本机装重模型，M2 联调前）
```bash
export DASHSCOPE_API_KEY=你的百炼key
uv sync --extra ml --extra pdf   # MinerU + PaddleOCR + FlagEmbedding + dashscope + PyMuPDF
uv run uvicorn app.main:app --port 8000
```
> 首次请求会懒加载模型（慢属正常）；`/rerank` 首次会下载 `BAAI/bge-reranker-v2-m3`。

## 5. 与 Java 的契约（M2 对接）

Java `DocProcessorClient`（M2 建）用 `RestClient` 调 `http://localhost:8000`，超时 30s；任何 `ok:false` 或不可达 → 降级 Tika 兜底 / score+MMR（§9.5 降级），不阻断主流程。

## 6. 已知限制

- 沙箱无 GPU、未装 ml extra，MinerU OCR / bge-reranker / Qwen-VL 的**真实推理**未在本环境跑通，需本机 `uv sync --extra ml --extra pdf` 联调（接口契约与降级路径已验证）。
- MinerU 的 magic-pdf API 以安装版本为准，`routers/parse.py` 中为其编排骨架，装好后可能需按版本微调字段映射。
